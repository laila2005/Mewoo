# ☁️ PetPluse Serverless API

This directory contains the serverless function configurations and endpoint mappings used for deploying the PetPluse backend to serverless platforms like Vercel.

## 📝 Purpose

In a modern, serverless architecture, long-running Node.js processes are often replaced or augmented by stateless serverless functions. This directory helps bridge the gap between our Express application (`/backend`) and the deployment environment.

## 🚀 Deployment

When pushed to Vercel or a similar hosting provider, the configurations here help route HTTP requests to the appropriate Lambda functions, ensuring rapid scaling and global edge distribution.
