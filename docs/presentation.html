07 / Zero-Disk Persistence

Memory-Buffered Cloudinary Upload Proxy

Buffer Proxy

☁️ Memory Streaming Flow

File uploads are prime targets for Remote Code Execution (RCE). To mitigate this risk, PetPulse avoids writing files to server disk entirely.

Instead, the gateway receives files into an Express memory buffer using `multer`, converts them to a Base64 Data URI string, and proxies them to the Cloudinary REST endpoint securely.

🛡️ Sub-Millisecond WAF Advantages

Unlike heavy ML model checks that add latency to every request, PetPulse implements a highly deterministic, compiled Express middleware.

  • No API Latency: Express parses 20 signatures in sub-milliseconds.
  • Zero Operational Cost: Run full security filters locally on serverless Vercel endpoints without relying on expensive LLM calls.
  • Immediate Log Persistence: Failed attempts are saved locally to logs/security.log.
