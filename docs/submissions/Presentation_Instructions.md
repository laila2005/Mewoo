# Presentation Upload Instructions

Your university portal requires a "Presentation" file to be uploaded. Since we built an incredibly advanced, interactive HTML presentation, here is how you can submit it.

### Option 1: Submit the Live Link (Recommended)
If the portal allows you to type a link or submit a text document, simply submit a text file containing your live Vercel link:
**https://presentation-petpulse.vercel.app**

### Option 2: Upload as a ZIP File
If the portal accepts `.zip` files, you should zip the entire `docs` folder (which contains your HTML file and all the images/assets) and upload it.
1. Go to your project folder: `G:\Mewoo\`
2. Right-click the `docs` folder.
3. Select "Compress to ZIP file".
4. Upload that zip file to the portal.

### Option 3: Export to PDF
If the portal strictly requires a `.pdf` file:
1. Open your live presentation in Google Chrome: `https://presentation-petpulse.vercel.app`
2. Press `Ctrl + P` to open the Print Dialog.
3. Set the Destination to **Save as PDF**.
4. Important: Go to "More Settings" and check the box for **Background graphics** so the dark colors and CSS styles appear in the PDF!
5. Click Save, and upload that PDF to the portal.
