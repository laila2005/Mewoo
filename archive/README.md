# 🗄️ PetPulse Archive

This directory serves as the historical vault for the PetPulse repository. It contains deprecated codebases, legacy architectural decisions, and older project deliverables.

## 📦 Contents

- **`legacy/`**: Contains the original, outdated client-side and server-side implementations before our migration to the modern React/Vite stack. Also includes early SQL migration drafts.
- **Outdated Documents**: Early stage business canvas models, initial proposals, and draft documents that are no longer actively maintained.

## ⚠️ Notice to Developers

Files in this directory are preserved strictly for historical reference, academic auditing, and fallback purposes. 

**Do not import, require, or depend on any code located in the archive.** Active development should occur in the `petpulse-web` and `backend` directories (the AI agent lives in `backend/src/ai/`).
