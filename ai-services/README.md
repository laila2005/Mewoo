# PetPulse AI Services 🧠

The **Agentic AI Microservice** powering the intelligence layer of the PetPulse Ecosystem. Built as an isolated Node.js/Express service, it integrates directly with LangChain and the OpenAI SDK to provide autonomous pet care triage and platform moderation capabilities.

## Architecture & Responsibilities

This microservice is completely decoupled from the primary Relational Engine (PostgreSQL) and the Core Zero-Trust API Gateway. It serves as a stateless orchestration engine where distinct "Agents" are defined to handle natural language processing (NLP) tasks.

### 🏥 Core Agents

#### 1. Vet Triage Copilot (`vetTriageAgent.js`)
Acts as the front-line medical dispatcher during stressful pet emergencies.
- **Natural Language Parsing**: Evaluates unstructured user input (e.g., *"My husky hasn't eaten in two days and is lethargic"*).
- **Urgency Classification**: Deterministically categorizes the severity into one of three buckets: `EMERGENCY`, `URGENT`, or `NORMAL`.
- **Diagnostic Mapping**: Formulates potential underlying diagnoses and immediate safe-action advice.
- **Dispatcher Integration**: Structurally returns JSON payloads designed to be consumed by the frontend to immediately route the user to the nearest PostGIS-located emergency clinic.

## Tech Stack

- **Runtime**: Node.js
- **Framework**: Express.js
- **AI Orchestration**: LangChain (`@langchain/core`, `@langchain/openai`)
- **LLM Engine**: OpenAI API

## Setup & Local Development

1. **Install Dependencies**
   ```bash
   cd ai-services
   npm install
   ```

2. **Environment Configuration**
   Create a `.env` file in the root of this directory and add your OpenAI Key:
   ```env
   PORT=5001
   OPENAI_API_KEY=sk-your-openai-key-here
   ```

3. **Run the Server**
   ```bash
   # Development mode (auto-reload)
   npm run dev

   # Production mode
   npm start
   ```

## Endpoints

### `GET /health`
Validates the microservice is active and securely reachable by the main API Gateway.

### `POST /api/agents/triage`
**Payload**:
```json
{
  "symptoms": "Description of the pet's condition"
}
```
**Returns**: A structured JSON object generated by the LLM containing the risk level, immediate actions, and routing directives.
