# 🎨 PetPulse Web Frontend

Welcome to the client-side application of PetPulse! This directory contains our modern, high-performance Single Page Application (SPA) built with React and Vite.

## 🌟 Technologies

- **Framework**: React 18
- **Build Tool**: Vite (for lightning-fast HMR and optimized production builds)
- **Styling**: TailwindCSS for rapid, utility-first styling and a beautiful, consistent design system.
- **Routing**: React Router DOM
- **State Management**: React Context API & custom hooks
- **HTTP Client**: Axios

## 📁 Directory Structure

- `src/assets/`: Static assets including images, icons, and global styles.
- `src/components/`: Reusable, modular UI components (Navbars, Modals, Product Cards).
- `src/context/`: Global state management for Authentication, Cart, and User Preferences.
- `src/pages/`: Top-level route components representing full views (Dashboard, Marketplace, Community, Auth).
- `src/utils/`: Helper functions, formatting utilities, and API interceptors.

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js installed. We recommend v18+.

### Setup Instructions

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start the Development Server**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

3. **Production Build**
   To compile and minify for production:
   ```bash
   npm run build
   ```

## 🎨 Design Philosophy

Our design language focuses on a premium, energetic aesthetic. We leverage a "Pulse" visual identity featuring deep violet/teal color palettes, glassmorphism elements, and subtle micro-animations to create an engaging experience for pet parents and professionals alike.
